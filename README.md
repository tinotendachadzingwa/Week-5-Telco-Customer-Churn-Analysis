# Telco Customer Churn Analysis 📊

## Project Overview

This project focuses on analyzing customer churn in the telecommunications industry to identify factors influencing customer attrition and provide data-driven recommendations for improving customer retention.

The analysis was completed as part of the **AnalystLab Africa Data Analytics Internship – Week 5 Business Analytics Case Study**.

---

## Business Problem

Customer churn is a major challenge for telecommunication companies because losing customers affects revenue and growth.

This project aims to answer:

**Why are customers leaving the company, and which factors contribute most to customer churn?**

---

## Dataset

**Dataset:** Telco Customer Churn Dataset
**Source:** Kaggle

Dataset details:

* Original records: 7,043 customers
* Cleaned records: 7,032 customers
* Features: 21 variables
* Target variable: Churn (Yes/No)

The dataset contains customer demographics, services, contract information, payment methods, and billing details.

## Analysis Process

The project followed these steps:

### 1. Data Cleaning

* Checked data structure and data types
* Assessed missing values
* Converted `TotalCharges` into numeric format
* Removed incomplete records
* Prepared a clean dataset for analysis

### 2. Exploratory Data Analysis (EDA)

Analyzed customer churn patterns through:

* Churn distribution
* Contract type analysis
* Monthly charges comparison
* Customer tenure analysis
* Payment method analysis

### 3. Dashboard Development

Created an interactive Power BI dashboard to present key performance indicators and churn insights.

---

## Key Insights

* **26.58%** of customers churned, while **73.42%** were retained.
* Month-to-month contract customers recorded the highest churn rate (**42.71%**).
* Churned customers had a higher average monthly charge (**74.44**) compared to retained customers (**61.31**).
* Customers with shorter tenure showed a higher likelihood of leaving.
* Electronic check users recorded the highest number of churned customers (**1,071**).

---

## Business Recommendations

* Encourage customers to adopt longer-term contracts through incentives.
* Improve onboarding and early engagement strategies for new customers.
* Review pricing plans to improve customer value perception.
* Investigate payment challenges affecting electronic check users.
* Develop targeted retention campaigns for customers at high risk of churn.
